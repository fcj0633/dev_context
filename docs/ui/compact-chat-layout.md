# 紧凑提问框与顶部会话栏

日期：2026-10-20。改造基线：`1d0f682`。本次只调整聊天界面和浏览器测试隔离，不改变后端 API、模型配置、回答引擎或流式协议。

## 实现

- 顶部会话栏桌面和手机统一为 48px。标题单行省略，历史菜单保留；480px 及以下隐藏证据标识，优先展示标题。
- 输入区改为同一横向框内的 textarea、Fast/Full 和发送/停止按钮，取消独立底部操作栏。
- 输入框外壳默认 56px；textarea 从一行 24px 自动长高，最多三行 72px，超出后内部滚动。三行时外壳为 84px。
- 文字改变、粘贴、建议问题填入和宽度变化后重新计算高度；清空、发送成功和新建会话后恢复单行。ResizeObserver 只响应宽度变化，卸载时释放；不支持该 API 时使用窗口 resize 事件。
- 保留 Enter 发送、Shift+Enter 换行、中文输入法组合保护、10,000 字限制、空问题禁发和请求期间的停止/模式禁用行为。
- 模式选择器与发送/停止按钮高 44px；“回答模式”标签视觉隐藏但仍可被辅助技术识别。
- 移除常驻证据提醒与快捷键说明，快捷键通过输入框 title 提供。错误、重连和取消等待信息按需出现。
- 保留手机底部安全区；正文、历史会话和证据抽屉沿用原行为。

主实现位于 `frontend/src/ChatPage.vue` 和 `frontend/src/style.css`。

| 视口 | 顶部栏：原 / 新 | 输入框外壳：原 / 新 | 底部区域：原 / 新 | 回答滚动区增加 |

| 桌面 1440×900 | 72 / 48px | 132.8 / 56px | 189.8 / 76px | 约 138px |

| 类型检查与生产构建 | 通过，已更新本机 frontend/dist |

| 原有流式回归 | Fast/Full 首段提前显示、正式片段稳定、刷新恢复、取消/复制、引用、失败/部分状态和断网恢复通过 |
| 已有用户 Web | 8000 服务进程未停止；健康检查通过，新构建已由原服务展示 |

首次浏览器运行发现窄屏占位文字折行，导致空输入框意外升高，并影响新会话恢复。已改为按真实输入内容计算高度、缩短占位文字，并在四个视口断言空框为单行；修复后全部通过，没有放宽目标尺寸。

用户 Web 正在占用 8000，因此测试替身使用独立 8001 端口。Playwright 和 Vite 开发代理增加可选测试地址配置，原测试中的释放生成器请求使用同一地址，避免误发给用户 Web；默认端口和普通开发行为不变。测试启动的替身和开发服务由 Playwright 在结束时清理。

复现（在 frontend 目录）：

```powershell
npm test
npm run build
$env:PLAYWRIGHT_API_PORT = '8001'
npm run test:e2e
```

没有修改 Python 生产实现，也没有调用真实模型、重新索引或修改用户知识库。移动端验证为 Chromium 视口模拟，未宣称覆盖真实 iOS/Android 软键盘或所有浏览器。
